## Notice Announcement

Notification and announcement plug-in, used to publish system internal notifications and announcements

-Support maintenance of system notifications and announcements
- Suitable for background announcements, site notifications, etc.

## Plug-in type

- Extension-level plug-ins
-Extension target: `admin`

## Configuration instructions

The current plug-in requires no additional configuration

## Usage

1. After installing and enabling the plug-in, restart the backend service
2. Maintain notification announcement content through the backend page or Swagger

## Uninstall instructions

- No additional cleaning of environment variables or plug-in configuration is required after uninstalling the plug-in
- If the front-end page or business logic already relies on notification and announcement capabilities, please clean up the corresponding integration simultaneously.
