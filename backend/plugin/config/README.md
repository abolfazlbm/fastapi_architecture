## Parameter configuration

Parameter configuration plug-in, usually used for dynamic maintenance of system parameters and configuration data required for front-end engineering display

- Support maintenance system parameter configuration
- Suitable for front-end engineering display data and system-level dynamic parameter scenarios

## Plug-in type

- Extension-level plug-ins
-Extension target: `admin`

## Configuration instructions

The current plug-in requires no additional configuration

## Usage

1. After installing and enabling the plug-in, restart the backend service
2. Manage parameter configuration data through the system backend page or Swagger

## Uninstall instructions

- No additional cleaning of environment variables or plug-in configuration is required after uninstalling the plug-in
- If the business code or front-end page already relies on parameter configuration capabilities, please clean up the corresponding integration simultaneously.
