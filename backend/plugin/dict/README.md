## Dictionary management

Data dictionary plug-in, usually used to maintain dictionary types, dictionary data, and constrain enumeration display and option mapping in front-end projects

- Supports maintaining dictionary types and dictionary data
- Suitable for unified dictionary scenarios such as front-end status values, classification values, drop-down options, etc.

## Plug-in type

- Extension-level plug-ins
-Extension target: `admin`

## Configuration instructions

The current plug-in requires no additional configuration

## Usage

1. After installing and enabling the plug-in, restart the backend service
2. Maintain the dictionary type first, and then maintain the corresponding dictionary data
3. Use stable dictionary encoding to maintain front-end enumerations and option mappings

## Uninstall instructions

- No additional cleaning of environment variables or plug-in configuration is required after uninstalling the plug-in
- If the front-end or business code already relies on dictionary capabilities and dictionary encoding, please clean up the corresponding integration simultaneously.
